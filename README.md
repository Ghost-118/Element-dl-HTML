# Element dl HTML

Proyecto enfocado en la estructuración de listas de descripción semánticas mediante el uso del elemento `<dl>` en **HTML5**. Muestra cómo organizar pares de términos (`<dt>`) y sus respectivas descripciones (`<dd>`) utilizando como ejemplo los principales navegadores web del mercado.

---

## 🚀 Características

- **Uso Semántico de Listas:** Implementación correcta del trinomio de etiquetas `<dl>`, `<dt>` y `<dd>` para asociar nombres de navegadores con sus descripciones.
- **Diseño Adaptativo Básico:** Configuración de la etiqueta `<meta name="viewport">` para garantizar una visualización adecuada en pantallas móviles.
- **Estructura Accesible:** Claridad en la jerarquía de información orientada a lectores de pantalla.
